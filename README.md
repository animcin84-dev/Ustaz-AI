# 🇰🇿 Ustaz-AI Pro Max (v2.0)

**Ustaz-AI Pro Max** — это передовая экосистема на базе искусственного интеллекта, разработанная специально для учителей Казахстана. Проект направлен на автоматизацию рутинных задач, создание качественных методических материалов и защиту прав педагогов в соответствии с законодательством РК.

---

## 🚀 Основные возможности

### 📄 Генератор КСП (Краткосрочных планов)
*   Генерация планов уроков строго по **Приказу №130 МОН РК**.
*   Автоматическое определение целей обучения (ГОСО), SMART-целей и критериев оценивания.
*   Структурированные этапы урока с указанием времени, активностей и методов ФО.

### 💡 Мозговой штурм 2.0
*   Генерация инновационных идей для уроков.
*   Разделение на блоки: Методология, Цифровые инструменты, План активности, Система оценивания, Домашнее задание и уникальная "Фишка".
*   Учет контекста цифровизации и обновленного содержания образования.

### 📚 Интеллектуальная библиотека
*   **Чтение документов**: Настоящая экстракция текста из **PDF** и **DOCX** файлов.
*   **Предпросмотр**: Возможность видеть содержание файлов прямо в браузере.
*   **Загрузка своих ресурсов**: Учителя могут добавлять свои материалы для мгновенного анализа ИИ.

### 🛡️ «Қорғаушы» (Юридический помощник)
*   Специализированный ИИ-адвокат для защиты прав учителей.
*   База знаний: Закон «О статусе педагога», Приказы №125 и №130.
*   Точные ссылки на статьи законов и готовые инструкции по отказу от несвойственных функций.

### 🔍 Smart Archive & Vision AI
*   **Универсальный ввод**: Анализ фотографий журналов, приказов и рукописных заметок через Gemini Vision.
*   **Умный поиск**: Поиск по архиву созданных документов с использованием ИИ-контекста.
*   **Экспорт**: Выгрузка аналитики и отчетов в Excel (форматы для 1С/Kundelik).

## ⚙️ Установка и запуск

### Предварительные требования
*   Python 3.10+
*   Node.js 18+
*   API Ключ Gemini (или Groq)

### 1. Настройка Backend
```bash
cd backend
python -m venv venv
source venv/bin/activate  # Для Linux/macOS
# или venv\Scripts\activate для Windows

pip install -r requirements.txt
# Дополнительно для обработки документов:
pip install PyPDF2 python-docx "pydantic[email]" email-validator
```

Создайте файл `.env` в папке `backend`:
```env
GEMINI_API_KEY=your_gemini_api_key
GROQ_API_KEY=your_groq_api_key
SECRET_KEY=your_secret_key
```

### 2. Настройка Frontend
```bash
cd frontend
npm install
```

### 3. Запуск проекта
Вы можете запустить всё одной командой из корневой директории:
```bash
./start.sh
```
Или по отдельности:
*   **Backend**: `cd backend && uvicorn main:app --reload` (порт 8000)
*   **Frontend**: `cd frontend && npm run dev` (порт 5173)

## 📜 Законодательная база
Проект опирается на следующие нормативно-правовые акты Республики Казахстан:
1.  **Закон РК «О статусе педагога»**.
2.  **Приказ МОН РК №130** (Оптимизация документооборота).
3.  **Приказ МОН РК №125** (Типовые правила проведения текущего контроля успеваемости).
